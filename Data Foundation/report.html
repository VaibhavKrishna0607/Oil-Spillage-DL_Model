Stage 2: Mask Quality Assessment + Normalization Statistics

What it did:

  1. Checked mask quality: For every mask, computed what % of pixels are "oil" (non-zero). Flagged outliers:
    • Nearly empty (<0.1%) — likely intentional negatives
    • Mostly oil (>70%) — likely mislabeled look-alike or land
  2. Computed normalization stats from TRAINING ONLY: This is critical.
    • Loaded all 5,255 training images
    • Computed pixel value statistics (mean, std)
    • Clipped outliers at 2nd and 98th percentile
    • Saved these numbers as frozen config

Why it matters: Computing stats on the entire dataset (train + val + test) is a silent data leak. When you normalize validation data using validation stats, your validation scores are artificially inflated. We only use training stats for everyone.

Stage 3: Group-Aware Split + Geometric Properties + Tensor Packing

What it did:

Part A: Group-Aware Split (prevents scene leakage)

The old way (WRONG): Shuffle all filenames randomly, take first 80% for train, last 20% for test.

The problem: If image `palsar_001.png` and `palsar_002.png` come from the same SAR acquisition scene, the model learns scene-specific noise patterns in training, then "validates" on a near-duplicate from the same scene. Your metrics look great but the model fails on truly new scenes.

The new way (CORRECT): Extract scene IDs from filenames (palsar_00, palsar_01, etc.), then split by scene group. Now each scene goes entirely to train OR test, never both.

Part C: Tensor Packing (fast loading)

What it did: Converted all PNG files into efficient PyTorch tensor format:

Train: 8,070 individual PNG reads per epoch
           ↓ (OLD - SLOW)
       ~8,000 disk seeks per epoch

Train: 1 tensor file load per epoch
           ↓ (NEW - FAST)
       ~30ms for entire training set

Process:

  1. Load each image as grayscale
  2. Apply frozen normalization: (img - 108.27) / 53.42
  3. Load mask, binarize (0 or 1)
  4. Convert to PyTorch tensors
  5. Stack all images/masks per split into one big tensor
  6. Save to `.pt` file (PyTorch format)
