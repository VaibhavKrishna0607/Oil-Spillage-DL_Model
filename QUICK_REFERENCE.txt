Q: Training is very slow (1 epoch = 30+ minutes)
A: Check if using GPU. Look for "Device: cuda" in output.
   If CPU: Install GPU drivers or use --batch-size 4

Q: Loss turns to NaN
A: Learning rate too high. Retry with --lr 1e-5

Q: No improvement for many epochs
A: Try longer training (--epochs 40) or lower LR (--lr 1e-5)

Q: CUDA out of memory
A: Reduce batch size: --batch-size 8

Q: Can't find module 'conpty.node'
A: Use train.bat directly or python run_training.py instead
