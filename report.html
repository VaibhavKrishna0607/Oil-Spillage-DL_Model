SAR Data Engineering (P1)

  • Standardized Dataset Splits: Processed 6,455 train and 1,615 validation images, mapping out explicit 80% training and 20% test-set mappings with static seeding for complete reproducibility.
  • Speckle Jitter Augmentation: Implemented joint spatial transforms (horizontal/vertical flipping, orthogonal 90-degree rotations, and contrast/brightness jitter) combined with Gaussian noise to simulate radar speckle and eliminate model overfitting.
  • Zero-Error Verification: Ran a clean verification sweep auditing all 8,070 images to confirm image-mask size alignment and pixel ranges.

Custom U-Net Segmentation (P2)

  • Model Architecture: Wrote a standard PyTorch contracting-expanding U-Net with DoubleConv layers, skip connections, and bilinear/transposed expansion blocks customized for high-accuracy binary segmentation.
  • Imbalance-Resistant Loss: Built hybrid BCE+Dice loss with a weighted cross-entropy factor of `2.9` based on true pixel ratios to prevent models from learning trivial negative-class mapping shortcuts.
  • Production Export Formats: Built validation scripts that successfully serialize state-dict parameters into **TorchScript (`best_model.pt`)** and **ONNX (`best_model.onnx`)** formats.

Laying the Foundation (P3 - P6 Roles)

Our P1 + P2 steps have output a clean, static-input processing system. Here is the blueprint for laying down the remaining three pipeline layers:

P3: Live AIS Data Ingestion

  • WebSocket Client: Bind to `aisstream.io` for streaming NMEA-0183 or JSON messages, saving coordinate points (Lat, Lon, Heading, Speed) into a spatial database index.
  • Vessel Near-Query: Build queries using PostGIS or bounding boxes: "Get vessels passing within X km radius of target polygon, within a Y-hour window."

P4: FastAPI Correlation Engine

  • Multi-Model Inference: Expose a `/detect` endpoint loading the optimized ONNX model using `onnxruntime` (reducing RAM overhead on backend host).
  • Mathematical Risk Scoring: Classify suspects using the spatial risk equation:
    Score = (1 / dist) × (1 / time_gap) × speed_anomaly_flag

P5: Mapbox GL Dashboard

  • Interactive Map Overlay: Draw GeoJSON polygons returned by `/detect` overlays, matching them visually with ship markers.
  • Card Alerts: Present structured highlight cards explaining the exact score reasons for top suspects.

P6: Docker Orchestration

  • Compose Stack: Run the web UI, FastAPI app, and database together with one single command: `docker-compose up --build`.
  • DevOps Reliability: Prevents dependency resolution issues on judges' presentation machines.
